# AplinkosRizika


Renkiesi būstą ir nežinai, kuo vienas rajonas skiriasi nuo kito? Mes kuriame įrankį, kuris surenka oficialius duomenis apie rajono saugumą, aplinką ir infrastruktūrą, tam, kad galėtum viską palyginti objektyviai ir vienoje vietoje. 


Not sure how one neighborhood differs from another when looking for a place to live? We're building a tool that collects official data on neighborhood safety, environment, and infrastructure - so you can compare everything objectively and in one place.
